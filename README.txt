OVERVIEW 

  Dare is a personal project for handling dynamically allocated arrays, it
is primarily designed around macros and places a header before that data
in order to keep track of sizes and elements.

    In other words it still enables the type safety of C without having to
type cast which was what the original implementation of the library did.

WHY

    This project has primarily been brought about due to my fascination with
C and it's bare bones nature, as well as my attempts at becoming a better
programmer.

    This is really just a small piece in a wide array of data structures I
plan to implement by myself and hopefully extended to the point where someone
professional might consider the library.
