OVERVIEW 

  Dare is a personal project for handling dynamically allocated arrays.

    Overall it allocates the array in one large chunk but only really returns
the data this allows for type safety while still being able to access it like
it's a conventional array albeit at some trade offs.

WHY

    This project has primarily been brought about due to my fascination with
C and it's bare bones nature, as well as my attempts at becoming a better
programmer.

    This is really just a small piece in a wide array of data structures I
plan to implement by myself and hopefully extended to the point where someone
professional might consider the library.
